# Идеология

Ввести репозиторий проекта - порт mcp for linux

Актуальный репозиторий сохранять на github.

После цикла изменений при фиксации определённого результата делать фиксацию изменений репозитория. Так, чтобы можно было проследить историю разработки по репозиторию. 

Результатом должно являться рабочее приложение для Linux.  


# Справка 1С: встроенный бандл

## Решение (принято 2026-11-07)

Справка платформы 1С поставляется внутри репозитория и порта. Скачивание с
сайта 1С и создание фиктивных каталогов `/opt/1cv8` не нужны. Источник файлов —
установленная на машине разработчика платформа, на данный момент 8.3.27.2342.
Отдельной поддержки старых версий справки нет: в порту лежит актуальная.

## Механизм

- Файлы: `data/1c-help/<версия>/` — три `.hbk` из каталога версии платформы
  (`shcntx_ru.hbk`, `shlang_ru.hbk`, `shquery_ru.hbk`). Имя каталога — точный
  номер вида `8.3.27.2342`: на нём держатся регексп `^\d+\.\d+\.\d+\.\d+$`,
  извлечение версии и префикс `topic_id`. Рядом `README.md` с указанием
  источника и правообладателя (файлы издания 1С).
- Поиск в `HelpIndexer.FindPlatformPath()`, порядок = приоритет:
  1. переменная окружения `CONFASTER_1C_HELP_PATH`;
  2. `1c-help/` рядом с бинарником (раскладка tarball);
  3. `/usr/share/confaster-mcp/1c-help` (раскладка .deb);
  4. установленная платформа: `/opt/1cv8/...`, `/opt/1C/1cv8/...`, Windows-пути.
  Встроенный бандл приоритетнее установленной платформы.
- Пакеты: `build-deb.sh` ставит бандл в `/usr/share/confaster-mcp/1c-help/`,
  `build-tarball.sh` кладёт `1c-help/` рядом с бинарником.
- `smoke-test.sh`: инструменты справки (`search_1c_help`, `get_1c_help_topic`,
  `list_1c_help_versions`, `reindex_1c_help`) ожидаются всегда, даже на машине
  без платформы 1С.
- Обновление версии справки: положить новый каталог `data/1c-help/<версия>/`,
  удалить старый, зафиксировать в `CHANGELOG.md`.

## Проверка результата

На машине без `/opt/1cv8`: сервер регистрирует четыре инструмента справки,
`list_1c_help_versions` показывает версию из бандла, `search_1c_help` находит
темы, `get_1c_help_topic` отдаёт текст.
