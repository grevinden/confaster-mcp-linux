# История релизов

Версия порта строится от версии апстрима: `<версия ConfasterMCP>-port.<N>`,
где `N` — номер сборки порта поверх одного и того же апстрима. Точный апстрим
определяется по `AssemblyInformationalVersion` в `ConfasterMCP.dll`
(например, `1.0.0+0c31141d…` — версия 1.0.0, коммит `0c31141d`).

Порядок работы при выходе новой версии апстрима: `scripts/check-upstream.sh`,
затем перекомпиляция (см. `docs/releases.md`).

## 1.0.0-port.6 — 2026-11-07

Апстрим тот же: `1.0.0+0c31141d`. Справка платформы 1С встроена в поставку.

### Добавлено

- `data/1c-help/8.3.27.2342/` — файлы справки (`shcntx_ru.hbk`, `shlang_ru.hbk`,
  `shquery_ru.hbk`) входят в репозиторий и во все пакеты. Инструменты справки
  работают на машине без установленной платформы 1С.
- `HelpIndexer.FindPlatformPath`: порядок поиска — `CONFASTER_1C_HELP_PATH`,
  `1c-help/` рядом с бинарником, `/usr/share/confaster-mcp/1c-help`,
  затем установленная платформа. Встроенный бандл приоритетнее платформы.
- `build.sh` копирует бандл в `dist/1c-help`, `build-deb.sh` — в
  `/usr/share/confaster-mcp/1c-help`, `build-tarball.sh` — рядом с бинарником.

### Изменено

- `scripts/smoke-test.sh` требует все четыре инструмента справки всегда,
  в том числе без установленной платформы 1С.

## 1.0.0-port.4 — 2026-11-07

Апстрим тот же: `1.0.0+0c31141d`. Уточнена документация по форматам исходников.

### Исправлено в документации

- Явно описаны оба поддерживаемых формата: полная выгрузка из Конфигуратора
  и проект 1C:EDT. С примерами структуры каталогов и указанием, что формат
  определяется автоматически, а корни разных форматов можно смешивать.
- Зафиксировано ограничение EDT: метаданные хранятся в `*.mdo` и не
  разбираются, поэтому `list_objects`, `get_object_structure` и
  `find_function_in_object` на EDT-проекте пусты — так же ведёт себя оригинал.
  Поиск по коду, символы, ссылки, контекст и граф вызовов работают полностью.
- Исправлен разделитель имени расширения: `имя|путь` (было указано `имя=путь`,
  код использует `|`).
- Уточнение внесено в `.github/README.md`, `docs/README.md`, `docs/usage.md`,
  `docs/install.md`, `docs/tools.md`, `docs/architecture.md`.

## 1.0.0-port.1 — 2026-11-07

Первая публичная сборка порта. Апстрим: ConfasterMCP 1.0.0+`0c31141d`,
дистрибутив `Confaster.zip` (`sha256 a4f2221c42de6ca3a4e0b40b4574101be3039966bf54adc68dd2fea0e9128a98`).

### Добавлено

- Порт MCP-сервера 1c-search под Linux: сборка из декомпилированного исходника
  на .NET 8, запуск через `dotnet ConfasterMCP.dll` и self-contained apphost.
- Сборка `libtree-sitter-bsl.so` из исходников грамматики (tree-sitter 0.25.6 +
  alkoleft/tree-sitter-bsl): символьные инструменты (`find_symbol`,
  `find_references`, `impact_analysis` и др.) работают.
- Поддержка Linux-раскладки справки 1С: `/opt/1cv8/x86_64/<версия>` без `bin/`,
  инструменты `search_1c_help`, `get_1c_help_topic`, `list_1c_help_versions`,
  `reindex_1c_help`.
- Пакет `.deb` (self-contained, без зависимости от dotnet-runtime) и бинарный
  архив `linux-x64`.
- CI на GitHub Actions: сборка, смоук-тест MCP, deb-пакет на каждый push;
  релиз с артефактами по тегу `v*`.

### Исправлено после сверки с апстримом

- Исходник порта был снят с устаревшей сборки `2e4ba670` и не содержал
  поддержку расширений. Передекомпилирован актуальный `624bfd22`
  (`1.0.0+0c31141d`), возвращены: аргумент `--extension-root`, параметр
  `configuration` у инструментов, разбивка статистики по конфигурациям,
  актуальные описания и схемы инструментов.
- Паритет с оригиналом подтверждён: 17/17 общих инструментов совпадают по
  `description` и `inputSchema`, плюс 4 справочных инструмента.

### Вне области порта

- GUI `Confaster.exe` (WinForms + WebView2) в порт не входит: предмет — только
  MCP-сервер, интерфейсом служит любой MCP-клиент. Потери возможностей
  MCP-сервера нет: схемы 17/17 и фактические ответы 13 инструментов совпадают
  с оригиналом (`scripts/compare-upstream.sh`, `scripts/compare-behavior.sh`).
