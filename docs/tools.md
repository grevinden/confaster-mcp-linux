# Инструменты

Всего 21: 17 основных (полный паритет с оригиналом) и 4 справочных.
`configuration` — имя расширения или `"основная"`; по умолчанию поиск идёт
везде. Параметры со `*` обязательны.

## Поиск кода

| Инструмент | Параметры | Назначение |
|---|---|---|
| `semantic_find` | `query`*, `context_objects`, `include_code`=true, `limit`=5 | поиск функции по описанию задачи (первый инструмент при неизвестном имени) |
| `search_code` | `query`*, `configuration`, `regex`=false, `scope`, `limit`=20 | поиск по тексту BSL/XML |
| `find_symbol` | `query`*, `exact`=false, `limit`=20 | найти процедуру/функцию по имени |
| `smart_find` | `query`*, `include_code`=true | найти символ и сразу вернуть его код |
| `find_references` | `symbol`*, `limit`=50 | все вхождения символа |
| `impact_analysis` | `object`* | какие модули и файлы используют объект/символ |

## Контекст кода

| Инструмент | Параметры | Назначение |
|---|---|---|
| `get_symbol_context` | `file`*, `line`*, `configuration` | полный код процедуры/функции по файлу и строке |
| `get_file_context` | `file`*, `line`*, `radius`=40, `configuration` | фрагмент файла вокруг строки |
| `get_function_context` | `function_name`* | граф вызовов: что вызывает функция и кто вызывает её |

## Объекты метаданных

Инструменты этой группы читают метаданные из XML-выгрузки Конфигуратора.
В проекте 1C:EDT метаданные хранятся в `*.mdo` и не разбираются, поэтому там
эти инструменты возвращают пустой список — так же, как оригинальный сервер.
Поиск по коду и символьные инструменты на EDT работают полностью.

| Инструмент | Параметры | Назначение |
|---|---|---|
| `list_objects` | `type`, `name_filter`, `configuration`, `limit`=100 | список объектов конфигурации |
| `get_object_structure` | `object`*, `configuration` | реквизиты, табличные части, формы, команды объекта |
| `find_function_in_object` | `object`*, `function_hint`, `configuration` | процедура/функция внутри конкретного объекта |

## Справка платформы 1С

Регистрируются всегда: справка входит в поставку (см. [install.md](install.md)).

| Инструмент | Параметры | Назначение |
|---|---|---|
| `search_1c_help` | `query`*, `category`, `limit`=5 | полнотекстовый поиск по справке |
| `get_1c_help_topic` | `topic_id`* | полный текст темы справки |
| `list_1c_help_versions` | — | статус индекса справки и статистика |
| `reindex_1c_help` | — | пересоздать индекс справки |

`category`: `syntax` — объектная модель и встроенный язык, `language` —
операторы и выражения, `query` — язык запросов, `all` — все разделы (по
умолчанию).

Поиск сначала пробует запрос целиком как фразу, а если так ничего не нашлось —
повторяет его как `AND` по словам. Поэтому `ВЫБРАТЬ ИЗ ГДЕ` находит темы, где
эти слова стоят не подряд.

Страницы, повреждённые в русских книгах, индексируются из английского дубля:
заголовок оканчивается на ` (en)`, в начале текста есть пояснение. Полный
список таких страниц — в [troubleshooting.md](troubleshooting.md).

## Когда инструмент недоступен

- символьные инструменты возвращают ошибку о `tree-sitter` — рядом с приложением
  нет `libtree-sitter-bsl.so` (см. [build.md](build.md));
- инструмент скрыт при запуске — указан в `--disabled-tool` или запрещён
  `--no-index-admin`.
