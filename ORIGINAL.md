# Оригинальный дистрибутив

Источник приложения: <https://confaster.ru/download/> (редирект на `https://confaster.ru/Confaster.zip`).

Свежая копия скачивается и распаковывается одной командой:

```bash
scripts/fetch-original.sh
```

Архив и распакованные файлы лежат в `original/`. Этот каталог намеренно
исключён из git-истории (см. `.gitignore`) — в репозитории только порт,
оригинал в любой момент восстанавливается скриптом.
