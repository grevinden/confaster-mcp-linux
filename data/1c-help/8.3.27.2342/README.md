# Справка платформы 1С

Файлы справки из установленной платформы 1С:Предприятие 8.3.27.2342:

| Файл | Содержание |
|---|---|
| `shcntx_ru.hbk` | синтаксис встроенного языка и объектов |
| `shlang_ru.hbk` | язык программирования |
| `shquery_ru.hbk` | язык запросов |

Источник: каталог установленной платформы `/opt/1cv8/x86_64/8.3.27.2342`.
Права на файлы принадлежат правообладателям платформы 1С. Файлы включены
для локального поиска по справке в MCP-сервере; отдельная поддержка старых
версий справки не ведётся.

Имя каталога — точный номер версии. Оно используется как версия индекса
справки и как префикс `topic_id` (`8.3.27.2342/syntax/...`).
